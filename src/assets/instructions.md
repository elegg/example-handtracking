# Instructions


## Main Author

If there is a corresponding author then select them as the main author. 

Normally the main author will be the first author.
However, if there is no link to the author (the author name will be in black not blue) this means there is no record for them on OpenAlex. Then you should take the next appropriate author (last author or next in line).


## Diamond Open Access Position

_Positive:_ if the author presents a positive view of the Diamond open access as a system. A positive position can include opinions that include some negative aspects - but these should not be on par with the positive takes.

_Neutral:_ Abstract contains no opinion on Diamond Open Access (e.g. mentions it as a model without any evaluation or judgement) *or* the opinion presented is ambivalent. 

_Negative_: The diamond open access model is presented in a negative or critical light. A negative position can include opinions that have negative aspects - but these should not be on par with the positive takes.
